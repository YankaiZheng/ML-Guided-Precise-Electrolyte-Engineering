# Development set release asset

The complete Candidate100-clean development matrix is distributed as the release asset:

`main_dataset.csv.gz`

Download it from [Release v1.0.0](https://github.com/YankaiZheng/ML-Guided-Precise-Electrolyte-Engineering/releases/tag/v1.0.0) and place it in this directory.

This table contains 60,641 development records, 3,562 columns, D in debye, and P in atomic units. The frozen 4,000-molecule internal test set is distributed separately under `../test/`.
